## B1 合成 ELF 的 section header table 曾耗时较多（已解决）

- **症状**：初版合成器用一遍式布局，`debug/elf` 报 `bad section name index`
  与 `EOF`。
- **根因**：section header 的 name offset 指向 `.shstrtab`，而字符串表的位置
  依赖前面所有段的大小——先建表后填偏移必然错位。
- **解法**：改成三遍式（定段内容 → 算字符串表与偏移 → emit）。已由
  `fixture_selftest_test.go` 守住。
- **遗留**：无。
